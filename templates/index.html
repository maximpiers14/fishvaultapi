FishVault API

A demo REST API serving the FishVault Android app

⚠️ This API was built for the Mobile Security course (Howest — Group 12). It contains intentional vulnerabilities used only for an authorized security assessment. It is not a production service and stores no real or personal data.

Available endpoints

GET /api/fish Full fish catalogue
GET /api/fish/<id> One fish by id
GET /api/health Service health check
GET /assets/<file> Fish images
